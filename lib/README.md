This directory contains libraries used for building for J2ME.

- `cldcapi11.jar` - CLDC 1.1 API (stub JAR from MicroEmulator)
- `midpapi20.jar` - MIDP 2.0 API (stub JAR from MicroEmulator)
- `proguard.jar` - [ProGuard 7.1.1](https://github.com/Guardsquare/proguard/releases/download/v7.1.1/proguard-7.1.1.zip), used for preverification of the JAR for J2ME.
